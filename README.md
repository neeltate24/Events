# 🎉 Meetup Events Platform (Full Stack)

💻 **Live Demo (Frontend):** https://events-vij7.vercel.app/
🛠️ **(Backend):** https://meetup-backend-seven.vercel.app/
💻 **Frontend:** React, JavaScript, CSS
🛠️ **Backend:** Node.js, Express (REST API)

---

## 📌 Overview

A full-stack event management platform where users can explore and manage meetup events.
The frontend is built with React, while the backend provides REST APIs to handle event data dynamically.

---

## 🚀 Features

* 📅 Browse all events
* 🔍 View detailed event information
* 🌐 API-based dynamic data
* 📱 Fully responsive UI

---

## 🧱 Architecture

* **Frontend:** React (UI + state management)
* **Backend:** Node.js + Express (REST API)
* **Data Flow:** Frontend ↔ Backend via API calls (JSON)

---

## 🔗 API Endpoints (Sample)

* `GET /events` → Fetch all events
* `GET /events/:id` → Fetch single event
* `POST /events` → Create new event

---

## ⚙️ Installation & Setup

### 1️⃣ Clone repository

```bash
git clone https://github.com/neeltate24/meetup-events.git
cd meetup-events
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run frontend

```bash
npm start
```

### 4️⃣ Run backend (if separate folder)

```bash
cd backend
npm install
node server.js
```
